## 요약

Portfolio-IT는 이미 레퍼런스의 섹션 순서를 그대로 따릅니다(히어로 → 로고 마퀴 → 스테이트먼트 + 벤토 → Works(Showcase/Grid/Deck) → Experiments → Ask → About/Journey → Stack → 별자리 그래프 → 손글씨 인용 → 푸터). 그래서 차이는 "무엇이 있느냐"보다 "어떻게 보이고 움직이느냐"에 몰려 있습니다. 가장 크게 다른 다섯 가지는 다음과 같습니다.

1. **레이아웃 프레임**: 레퍼런스는 폭 약 1200px 중앙 컬럼 안에 모든 내용을 두고, 컬럼 양옆 세로 가이드선과 섹션 사이 가로선, 교차점의 작은 점으로 "설계도" 느낌을 냅니다. 리포는 좌우 64px 여백의 전체 폭 레이아웃이고 가이드선이 없습니다.
2. **히어로 하늘 연출**: 레퍼런스는 구름 → 별 → 산 실루엣 → 서치라이트 빔이 약 15초 주기로 순환합니다. 리포는 별과 빔이 항상 켜져 있습니다.
3. **내비게이션 메가 메뉴**: 레퍼런스는 Work와 Experiments 모두 미리보기 패널이 있는 메가 메뉴를 열고, 맨 위에서도 마우스를 올리면 라벨이 펼쳐집니다. 리포는 Work에만 텍스트 드롭다운이 있고, 스크롤해야만 펼쳐집니다.
4. **Deck 카드 뒤집기**: 레퍼런스 덱은 카드를 탭하면 뒷면(설명·태그·링크)으로 뒤집힙니다. 리포는 탭하면 다음 카드로 넘어갑니다.
5. **ASCII 손 + 손글씨 애니메이션**: 레퍼런스는 인용문이 써지듯 나타나고, 그 아래 문자로 그린 두 손이 서로를 향해 다가갑니다. 리포는 인용문이 정적이고 ASCII 손이 없습니다.

## 구현하면서 함께 고친 기존 버그

- **Grid 보기가 항상 보이던 문제**: `.grid-view { display: grid }`가 `hidden` 속성을 덮어써서, Showcase나 Deck을 골라도 Grid 카드가 함께 렌더링되고 있었습니다. `.grid-view[hidden] { display: none }`을 추가했습니다. 레퍼런스처럼 한 번에 한 보기만 나오게 하려면 필요한 수정입니다.

## 구현 메모

- ASCII 손은 레퍼런스 원본 그림이 없어서, 팔·손바닥·손가락을 곡선으로 직접 그린 실루엣을 글자 격자로 바꿔 표현했습니다. 두 팔이 서로를 향해 뻗고 스크롤할수록 가까워지는 연출은 같지만, 손 모양 자체는 레퍼런스보다 단순합니다.
- 히어로 하늘 순환 주기(15초)와 각 단계 비율은 영상 05:40~06:55 구간에서 빔이 다시 나타나는 간격을 재서 정했습니다.
- 모든 새 애니메이션은 `prefers-reduced-motion`에서 멈추거나 최종 상태로 바로 표시됩니다.

## 구현하지 않은 것과 이유

- **테마 버튼이 내비로 들어가는 동작**: 화면 위치에 따라 버튼 두 개를 오가게 하는 것에 비해 얻는 효과가 작습니다.
- **픽셀 캐릭터 커서**: 사이트 기능인지 사용자 OS 커서인지 영상으로 확정할 수 없습니다.
- **외부 데모 사이트(턴테이블 등)**: 포트폴리오 본문이 아니라 별도 서비스입니다.
- **레퍼런스의 문구·프로젝트·사진**: 남의 콘텐츠이므로 가져오지 않고, 연출과 구조만 반영했습니다.
